# Python — Laboratórios e Projetos (freeCodeCamp)

Repositório com os exercícios práticos e os projetos de certificação da trilha
**Python (v9)** do freeCodeCamp — minha base de programação dentro do roteiro de
estudos que venho seguindo em Automação Industrial & IIoT.

## Sobre a trilha

O curso me leva dos fundamentos até tópicos mais avançados de Python, sempre no formato
"aprender construindo": cada conceito novo vira um pequeno projeto prático em vez de só
teoria. Ao longo do caminho, os laboratórios (labs) cobrem:

- **Fundamentos:** variáveis, estruturas de controle, funções
- **Lógica aplicada:** cifra de César, algoritmo de Luhn (validação de cartão)
- **Programação funcional:** funções lambda, list comprehensions
- **Manipulação de texto:** expressões regulares (regex)
- **Recursão e algoritmos:** Torre de Hanói, merge sort
- **Orientação a objetos:** classes e objetos (ex: solucionador de sudoku)
- **Estruturas de dados:** árvore binária

Depois dos laboratórios, a trilha fecha com **5 projetos de certificação**, feitos do
zero pra comprovar o domínio de tudo que foi estudado.

## Por que este repositório existe

Python é a linguagem-base de todo o meu roteiro de especialização — é o que conecta
lógica de programação, banco de dados (SQL) e automação industrial (IIoT) num fio só.
Este repositório é onde guardo essa base construída, tanto pra consulta futura quanto
como parte do meu portfólio.
